# 成長・加齢(Progression)設計

`docs/engine-roadmap.md` の Phase 5(シーズンをまたぐ繰り越し + 加齢・成長)の v1。
**状態: 実装済み**(`include/ProgressionEngine.h`, `src/ProgressionEngine.cpp`)。

## 何をするか

オフシーズンごとに、全員が1歳年を取り、能力値が動く。

- **成長中の選手(ドラフトの新人)**: `Player::potential`(天井)が `readiness`(今の段階)より高い間は、毎年ギャップの約40%(+運)ずつ天井に近づく。天井に達したら加齢カーブに移る。
  成長1段階あたりの能力値は **0.6**(ドラフトで作る時の 0.8 より控えめ。下の「既知の課題」参照)。
- **それ以外の選手**: 年齢カーブに従う。

| 年齢 | 1年あたりの平均変化 |
|---|---|
| 24歳以下 | +1.5 |
| 25〜26 | +0.5 |
| 27〜30 | 0 |
| 31〜32 | −0.7 |
| 33〜34 | −1.2 |
| 35歳以上 | −2.0 |

  さらに、足(打者)と球速(投手)は早く落ちる(29歳以降 −0.8、30歳以降 −0.8)。守備・肩・スタミナは遅れて落ちる。選球眼は30歳以降に少し上がる。
  毎年「選手ごとの好不調」(σ0.8)と「能力値ごとのばらつき」(σ0.8)が乗る。能力値は 30〜95 に収める。
- **その年に入った新人は、その年は成長も加齢もしない**(ドラフト時の能力値のまま入る)。

## 起用の入れ替え(depth)

能力値が動いたあと、ベンチの野手(同じポジション)や救援投手が、先発より総合値で **3以上** 上なら、その枠を奪う。成長した新人が先発の座を取れて、リーグが加齢だけで衰えるのを防ぐ。
救援が先発に上がるには、スタミナ60以上が必要。入れ替えた選手は、役割(`role` / `pitcherRole`)を交換する。

## シーズンの作り方(`buildSeasonRosters`)

`Teams.cpp` の手書きロスターが **2026年**。2027年以降は、毎年のオフシーズンを順に再生する。

```
2026: Teams.cpp のロスター
2027: ドラフト(シード=2027)→ 新人が枠に入る → 全員1歳加齢 → 入れ替え
2028: 2027年のロスターから、同じ手順(シード=2028)
```

- 乱数は全てシードで決まる(`std::*_distribution` を使わず、環境による差が出ない)。
- ドラフトは、その年のロスター(それまでのドラフトと加齢を反映済み)から行う。2027年のドラフトは、これまでの公開内容と完全に一致する。
- `game_export --draft` と `JojiDraftRunner` が、同じ関数を使う。

## 出力

`JojiDraftRunner` が `<out-dir>/progression/progression.json` を出す(その年の加齢の結果)。
`changes[]`: チーム・選手・年齢(前後)・総合値(前後)・成長中かどうか。

## 確認した結果(ローカルで 2027〜2034 を作成)

| 年 | 打線の平均 | 先発の平均 | 救援の平均 | 平均年齢 |
|---|---|---|---|---|
| 2026 | 65.9 | 68.5 | 67.4 | 28.1 |
| 2027 | 65.7 | 70.1 | 67.5 | 28.4 |
| 2028 | 65.4 | 70.9 | 68.0 | 28.6 |
| 2031 | 64.8 | 74.0 | 67.9 | 29.6 |
| 2034 | 64.4 | 77.3 | 67.4 | 30.0 |

全試合を作った結果の得点は、2027年 3.93 / 2028年 3.71 / 2030年 3.71 点(1試合あたり)で、極端には崩れない。

## 既知の課題

- **投手陣の水準が、年々少しずつ上がる**(先発が +1/年ほど)。各ドラフトクラスの有望株が先発に入る一方で、
  引退やFAで選手が抜ける仕組みがない。成長を 0.8 → 0.6 に抑えて緩めている。根本対応は引退・FA(roadmap Phase 3)。
- **引退がない**。高齢選手は下がり続けながら残る(入れ替えで、先発の座は若手に移る)。
- **ドラフトの `potential` は最大85**。天井が高い新人が、年々先発に集まる(上と同じ原因)。
- 2026年の公開データは、一切変わらない(2027年以降だけ適用)。
